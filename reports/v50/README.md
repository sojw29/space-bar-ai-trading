# V50 — 3D Control Room

Adds keyboard-accessible camera presets (overview, front, top, COMMANDER) and zoom controls to the V49 Three.js office. A monitor legend and additional static workstation details improve readability. Existing 2.5D page and local read-only research API remain unchanged.

Start the localhost research server and visit `http://127.0.0.1:8765/office3d` on the same PC. A browser with WebGL and network access for the pinned Three.js CDN module is required. Historical CSV data is needed to display historical research.

This is 3D visualization of fixed research heuristics, not autonomous character behavior or a live trading service. No market orders or private account connections are included. Offline CI checks JavaScript syntax and HTTP safety; browser visual quality and exchange connectivity are not covered.
